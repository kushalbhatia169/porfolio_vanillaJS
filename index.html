About Me

I'm a Senior Software Engineer with 6+ years of experience building and scaling cloud-native enterprise applications across React, .NET, and Azure.

At Deltek, I work on the Specpoint platform, including its content model, Cosmos DB architecture, and a React-based Track Changes engine. I migrated more than 40 million live Cosmos DB records from a two-partition-key to a three-partition-key model, manage Specpoint's Dela AI assistant, and optimized the Get Content API to reduce response time from 8 seconds to 1 second.

At Infosys, I worked on enterprise applications using React, GraphQL, and .NET Core. Earlier at JK Tech, I built reusable React components and worked on REST API migrations.

I enjoy taking on complex engineering problems end to end, from understanding user needs and shaping a solution to improving performance and supporting reliable releases. My focus is on high-performance UI systems, scalable cloud data, and maintainable software.
